# Source and license handling

The license engine, not an LLM, decides permitted operations. Search results are not proof of processing/export permission. Source, creator, original page, license and evidence are retained. Export rechecks permissions and writes attribution and a manifest.

- Art Institute: trust official is_public_domain plus image_id; use config.iiif_url. Official docs: https://api.artic.edu/docs/ . Conservative request pacing; image fetching may still be blocked by the source.
- The Met: official v1.1 search, object details isPublicDomain and primaryImage fields. https://metmuseum.github.io/ . Live search currently receives HTTP 403; per-provider connection test reports the error.
- Openverse: https://api.openverse.org/v1/ and schema snapshot in openverse-contract.json. Index license alone remains unverified; trusted Openverse-hosted thumbnails can be displayed, but no download/analysis/export.
- Pixabay: https://pixabay.com/api/docs/ ; result JSON cached 24 hours; key configurable. Temporary search thumbnails displayed via trusted Pixabay URLs. The official Content License permits creative derivative board exports; only-resized/cropped standalone image export is blocked. Saved boards use a local copy rather than permanent Pixabay hotlinks. This does not grant ML analysis rights.
- Unsplash: https://unsplash.com/documentation ; attribution/source links preserved. Official hotlinked images and photographer/Unsplash links are displayed. Editable reference boards store metadata only; selecting into a board triggers the official download_location event without caching the event. Re-saving/relayout does not re-report unchanged selections. Local ML analysis requires each user's separately confirmed local-inference scope. This enables temporary RAM-only processing, while original-image file storage remains disabled. Creative-board PNG/PDF export is separately allowed by the Unsplash License; each explicit export tracks each unique Unsplash photo and preserves author/profile/source/license links in sidecars. The declaration is recorded without treating it as independently verified source rights. See API Terms section 12 (AI/ML) and section 6 (hotlinking/events).
- Mock: original procedural fixtures for offline tests, explicitly labeled demo/CC0.
- Upload: requires explicit confirmation of rights; this is recorded as user-owned evidence, not independently verified ownership.

Verified CC0/public domain allowed; CC BY requires attribution. CC BY-SA, ND and unknown blocked from automatic export. NC blocked in commercial mode. Sources not authorized for ML analysis never enter the embedding pipeline. Separately licensed export rendering may decode image bytes without granting ML rights. No Pinterest scraping. No automated circumvention of HTTP challenges.
