# 使用指南

## 安装与首次启动

从本项目 GitHub Releases 获取 macOS arm64 的 DMG。打开后将应用拖至 Applications，再启动；无需安装 Python 或 Node。目标 macOS 14+，仅在 macOS 15.8.1 / M3 实际验证。尚未提供 Intel 或 Windows 安装包。

当前包只有 ad-hoc 签名，未完成 Developer ID 签名和公证，其他电脑可能阻止打开。先核对下载来源与 SHA256，按 macOS 系统提供的提示处理；不要关闭 Gatekeeper 等全局保护。若系统仍阻止，等待正式签名版本或在具备开发环境的机器从源码运行。

每份 Release 附 SHA256 校验文件。将 DMG 和 `.dmg.sha256` 放在同一目录，再执行：

```sh
shasum -a 256 -c AI-Mood-Board-Studio-0.1.0-macOS-arm64.dmg.sha256
```

## 无账号体验

设置 → 图片来源 → 开启「演示素材」。在检索页来源菜单只保留演示素材。输入任意设计描述，搜索、收藏、创建画布、保存和导出。演示图为程序绘制的几何图，不用于评估真实照片的搜索准确率。

## 搜索与整理

1. 设置页启用需要的来源；需要 Key 的来源先填写并保存自己的密钥，再测试连接。
2. 在顶部输入中文或英文描述，例如「银色金属、磨砂玻璃、灰蓝色灯光，简约工业设计」。
3. 检查检索计划与本次来源，发起搜索。来源失败信息不代表其他来源也失败。
4. 点击收藏，默认进入未分组；标签按钮可选择多个标签，也可创建新标签。
5. 主页使用「全部 / 未分组 / 自定义标签」浏览。管理标签可重命名或删除，删除标签不删除图片收藏。

收藏保存链接、作者、许可与标签等元数据，不等于保存原图。远程预览需要网络，源图被删除后可能失效。删除收藏不会删除已有画布中的素材实体。

## 单张下载

图片卡片按来源权限显示下载按钮；无法核实权限时打开原始来源。下载原图不意味着可以改编或导出拼贴。Unsplash 用户主动下载会按 API 规则上报事件；事件失败则停止交付。超出 40 MB 的文件会被拒绝，不支持批量下载。

## 创建与编辑画布

搜索后选择素材并创建画布，选择比例与三种布局之一。可拖动、缩放、替换、删除或锁定元素，加入色卡和文本，再保存到「我的项目」。重新打开项目继续编辑，也可复制项目尝试其他方向。

没有视觉模型时仍可用基础排序和布局。有模型时仅对具备分析权限的图片执行视觉筛选；结果提示中的设备与实际分析数量可用于确认是否采用了模型，模型可用不代表每一张图都获准分析。

## 导出

PNG / PDF 导出返回 ZIP，包含成品、`attribution.txt` 与 `license-manifest.json`。后端会重新核查许可，Unknown、限制改编或当前未开放导出的来源会阻止导出。可替换素材，或导入你确实拥有复制、修改及输出权利的图片。不要通过修改前端权限字段绕过检查。

## AI 设置

云端 AI 负责解析描述，不负责生成整张画布或版权判定。选服务商 → 填写 API Key → 保存 → 查询或手动输入 Model ID → 测试连接 → 启用云端解析。模型切换对下一次请求生效；测试连接会发送真实 API 请求，可能产生费用。

可以配置备用模型、单次 / 累计预算与价格。费用为估算，不是供应商账单；限额不能替代供应商侧费用控制。未配置或调用失败时会回退到规则解析。

SigLIP 视觉模型连接见 [模型说明](model-setup.md)。Unsplash 视觉分析需要额外授权，设置中的声明并不独立验证授权，也不授予文件导出权限。

## 数据、备份与更新

桌面版默认数据在 `~/Library/Application Support/AI Mood Board Studio`，密钥在系统钥匙串。关闭应用后备份整个数据目录；不要把密钥或用户数据提交 GitHub。模型独立备份。源码版默认 `.local/`，不会自动迁移到桌面版。

更新前先备份；关闭应用，将新版本拖入 Applications 替换应用。替换应用本体不用于删除用户数据。当前未实现自动更新或一键数据迁移。清理图片缓存不会删除项目、上传原件或模型。来源不允许缓存的图片不得转为持久存储。

## 常见问题

| 情况 | 处理 |
| --- | --- |
| 空结果 | 检查是否勾选来源、是否保存密钥；尝试更短英文关键词；用演示素材区分网络与应用问题 |
| 401 / 403 / 429 | 检查 Key、来源状态与额度，稍后重试；上游限制不会被应用绕过 |
| 模型尚未加载 | 模型按需加载；确认目录和版本清单完整、外接盘已挂载 |
| 模型离线 / 路径变化 | 重新选择模型目录，运行视觉筛选；不需要重新下载到内部磁盘 |
| 导出受限 | 查看许可信息并替换不满足权限的图片 |
| 无法保存 Key | 检查系统钥匙串服务；应用不会回退为明文保存 |
| 源码页面打不开 | 检查前端已 build，启动进程仍在、8765 端口未被占用 |

提交问题时附系统、版本和脱敏报错；不要上传密钥、包含隐私的日志或完整用户数据库。
