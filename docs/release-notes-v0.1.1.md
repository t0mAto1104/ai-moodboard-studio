修复 Unsplash / Pixabay 素材被一律阻止导出的问题。

- 按官方许可支持常规组合 Mood Board 的 PNG / PDF 导出，保留署名和许可清单。
- 打开旧项目时重新计算权限，无需重新搜索或重建画布。
- Unsplash 保留官方热链接；导出每张唯一照片上报下载事件，事件失败时停止交付；原始图片不落应用缓存。
- Pixabay 画布使用下载到本机的图片副本，避免永久热链接；仅缩放或裁切单图的输出仍不作为组合创作放行。
- 导出渲染与机器学习分析分开，未授权的 AI 分析不会因开放导出而启用。
- Unknown 许可、非法图片 URL 和不满足来源要求的素材仍阻止导出。

### 安装

下载 `AI-Mood-Board-Studio-0.1.1-macOS-arm64.dmg`，将应用拖入 Applications。更新前关闭旧应用并备份应用数据目录；本包沿用相同本地数据与钥匙串服务，不需要重建项目。附 SHA256 与 INSTALL.txt。

Apple Silicon / 目标 macOS 14+，实际验证 macOS 15.8.1 / M3。不含视觉模型、API Key 或开发者项目数据。仍为 ad-hoc 签名，尚未 Apple Developer ID 签名、公证。

### 验证

67 项后端、11 项前端测试及生产构建通过。新增模拟官方图库契约的 PNG/PDF、事件失败、旧项目权限、Unknown 阻止与不提升 AI 权限测试；独立应用自检同样实际执行两种来源的导出，但使用 Mock 网络，不冒充真实图库联网结果。另以两张现有真实 Unsplash 照片完成 PNG/PDF 联网导出，4 次官方事件成功，原图缓存写入为零，未修改现有项目。Pixabay 未提供密钥，仅作模拟网络验证。最终包另执行全新数据和只读镜像搬移自检。
