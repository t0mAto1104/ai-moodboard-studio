# 收藏与画板编辑

本地网页已支持从收藏创建画板。v0.2.0 安装包已包含此轮编辑功能；发布验证见 release-0.2.0.md。

## 从收藏制作

1. 主页点击「制作画板」。
2. 逐张选择，或打开标签后「选择当前分组」；可跨标签选取，总计 1–24 张。
3. 「创建画板」填写名称、比例并选择网格、材质或拼贴布局。
4. 进入编辑器。手动选择的图片全部保留，不启动视觉排序或 LLM 调用。

仅可用于画板的素材可选。收藏仍然只保存来源元数据；建立画板不会扩大图片许可。Unsplash 新选择的图片仍通过既有官方事件接口上报，失败会阻止创建或保存并显示错误。

## 编辑

- 素材：点击缩略图插入。选中画布图片后点「替换图片」，再点素材替换。
- 收藏：向当前项目添加其它已收藏素材，保存时保留来源关联。
- 导入：确认使用权后导入 PNG / JPEG / WebP，沿用后端下载、解码与文件安全限制。
- 布局：重新排列未锁定图片；文字、色卡和锁定元素保留位置。布局可撤销。
- 图层：选择、锁定与解锁。右侧可调整层级顺序。
- 画布：拖动、缩放、旋转。图片默认等比缩放，可通过宽高输入精确调整；旋转后的实际边界也会保持在画布内。
- 文字：编辑内容，选择无衬线、衬线或等宽字体、字号、粗体、对齐、行高、颜色。
- 色卡：矩形或圆形，支持颜色、大小、旋转、透明度和层级。
- 属性：坐标、尺寸、透明度、画布对齐；完整显示或居中裁切图片。
- 空白处取消选择后，可调整比例和画布背景。比例改变按比例映射元素，并约束旋转边界。
- 缩放与适应窗口仅影响编辑视图；100% 表示当前窗口适配尺度。导出始终使用画布原始像素尺寸。
- 画板名称、内容、背景和比例通过「保存」持久化。在应用内离开未保存画板或关闭浏览器时会提示。

## 快捷键

| 操作 | macOS / Windows 与 Linux |
| --- | --- |
| 保存 | Cmd / Ctrl + S |
| 撤销 | Cmd / Ctrl + Z |
| 重做 | Shift + Cmd / Ctrl + Z，或 Ctrl + Y |
| 复制选中元素 | Cmd / Ctrl + D |
| 全选 | Cmd / Ctrl + A |
| 多选 | Shift 或 Cmd / Ctrl + 点击画布元素；Shift + 点击图层 |
| 移动 | 方向键 1px；Shift + 方向键 10px |
| 删除 | Delete / Backspace，跳过锁定元素 |
| 取消选择 | Esc |

输入文字时保留标准文本编辑快捷键。撤销栈最多保存 80 次文档变更，包含背景、比例、名称和元素；重开项目后从已保存内容开始。拖拽/缩放在结束时记为一次操作。多选支持复制、删除、方向键移动和画布对齐；当前鼠标拖动只移动直接拖到的元素。

## 保存与导出

导出菜单支持 PNG / PDF，先保存当前文档，再由后端重新检查素材许可并渲染。输出 ZIP 同时包含 attribution.txt 和 license-manifest.json。参考素材不能因为收藏、手动插入或布局变换而获得导出权。

后端 LayoutItem 新增可回退默认值的 font_size、font_family、font_weight、text_align、line_height、shape 字段；项目新增 background。旧项目无需重建 SQLite 表：上述数据位于现有 JSON payload 内，读取/导出使用默认值兼容旧文档。字体仅能从固定内置类别选择，不接受任意字体文件路径。

## 范围

保留 Studio 现有白色导航、图片优先展示及来源信息，仅借鉴通用编辑能力。未接入 Canva，也不导入 Canva 私有模板。当前是单页画板，尚未实现多页文档、组合与解组、多元素共同拖拽、自由裁切焦点、抠图、视频、协作、自定义字体上传、云端发布或自动保存。导出字体受本机可用字体影响，字形度量与浏览器可能有细微差别；跨平台像素级一致性仍需专门字体打包方案。
