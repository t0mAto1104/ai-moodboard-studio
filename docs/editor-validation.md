# 收藏建板与编辑器验证

日期：2026-10-24。macOS Apple Silicon，现有 Python 3.12 / Node 环境复用，无新增依赖、无模型下载、无用户数据迁移。

## 修改范围

- Home.tsx：收藏跨标签选图、分组选择、名称/比例/布局建板对话框。
- App.tsx：手动建板入口、文档状态加载、编辑页简化顶部、未保存离开提示。
- Editor.tsx、Board.tsx、store/editor.ts、editor/geometry.ts：素材插入替换、收藏/导入/布局/图层、历史、键盘、几何边界、文字图形与缩放。
- types/models.ts、style.css、useLibrary.ts：数据类型、白色响应式编辑布局及稳定空集合。
- API schemas/models.py、routers/projects.py、exports/render.py：手动选择保留全部图片、权限复核与官方选择事件、样式/背景保存及 PNG/PDF 渲染。
- 新增前端 7 项测试和后端 2 项测试；操作说明见 editor-guide.md。

## 实际浏览器流程

在独立 localhost:8766 服务与临时 SQLite 测试目录运行，使用项目自身的 Mock Provider 图像，不改用户当前数据库或调用商业图库：

- 主页标签「材质研究」选择 5 张图，创建命名画板。
- 添加文字，修改字号、粗体、位置、宽度、对齐，保存。
- 鼠标拖动图片、旋转 30°，观察边界约束并撤销。
- 添加圆形，拖动缩放手柄，将约 120×120 调整为 164×164，锁定后删除/复制/对齐禁用，随后撤销。
- 从编辑器收藏面板新增另一张图并保存，再撤销并保存。
- 实际点击 PNG 导出，检查 ZIP 中图片、署名与许可清单，清单含 5 项来源。
- 刷新页面，从「我的项目」重新打开，标题、5 张图片及文字保留。
- 放大后「适应窗口」恢复。观察 1280px 与用户调整后的 625px 宽视口：窄屏属性区移至下方，图片栏及画布保持可操作。375px 手机视口、Windows/Linux 原生窗口和打包应用未在此轮验证。

最终本地服务 127.0.0.1:8765 已重启加载新后端，前端 dist 已重建；没有强制刷新用户正在编辑的浏览器标签。
